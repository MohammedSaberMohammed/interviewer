## When You Reach For It

Understand what modern build tools output: chunks, assets, source maps, minified code, and env replacements. Module and build decisions affect what code ships, when it loads, and whether production behaves like local development. The practical test is whether another engineer can predict the behavior from the code shape.

## Concrete Pattern

```javascript
const Chart = await import('./Chart.js');
Chart.mount(container);
```

Choose names and structure that preserve the business rule, not just the shortest syntax.

## Trap To Avoid

- Separate build-time replacement from runtime configuration.
- Know which dependencies are shipped to users or servers.
- Use code splitting where delayed loading improves startup.

Tooling knowledge is practical when you can explain the artifact: chunks, env replacement, dependency graph, and runtime format.
