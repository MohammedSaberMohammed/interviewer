## Failure Mode

Understand import/export, require/module.exports, package type, and interop pain points. Module and build decisions affect what code ships, when it loads, and whether production behaves like local development. Use the concept to narrow the failure mode, not to recite trivia.

## Working Pattern

```javascript
import { readFile } from 'node:fs/promises';
export async function loadConfig(path) { return readFile(path, 'utf8'); }
```

Leave the code in a shape that is easy to test at the behavior boundary.

## What To Verify

- Separate build-time replacement from runtime configuration.
- Know which dependencies are shipped to users or servers.
- Use code splitting where delayed loading improves startup.
