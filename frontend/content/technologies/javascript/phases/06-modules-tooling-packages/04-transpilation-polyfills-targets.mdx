## Bug Pattern

Know the difference between syntax transforms and runtime polyfills so browser support decisions are deliberate. Module and build decisions affect what code ships, when it loads, and whether production behaves like local development. Treat the syntax as a tool, then explain the operational consequence.

## Production-Friendly Code

```javascript
if (!Array.prototype.toSorted) {
  // load a polyfill only for browsers that need it
}
```

Reach for cleverness only after the plain version has a measured problem.

## Interview Angle

- Separate build-time replacement from runtime configuration.
- Know which dependencies are shipped to users or servers.
- Use code splitting where delayed loading improves startup.
