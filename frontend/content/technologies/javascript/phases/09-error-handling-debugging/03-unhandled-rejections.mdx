## Operational Context

Prevent promise failures from disappearing or crashing at the wrong layer. Bad error handling either hides the cause or crashes too far away from the real failure. The practical test is whether another engineer can predict the behavior from the code shape.

## Default Move

```javascript
void sendAnalytics().catch(reportError);
```

Choose names and structure that preserve the business rule, not just the shortest syntax.

## Risk Check

- Catch only where you can add context, recover, or report.
- Keep the original error available through cause or structured logging.
- Turn fixed bugs into tests when the behavior is important.

<Callout type="senior">
The professional move is not catching more; it is putting the boundary in the right place.
</Callout>
