## Failure Mode

Avoid forced synchronous layout and write DOM updates that cooperate with the browser rendering pipeline. Slow JavaScript blocks interaction; leaked references make sessions degrade the longer users keep the app open. A good rule of thumb is only valuable if it helps you choose safer code under pressure.

## Working Pattern

```javascript
const heights = cards.map((card) => card.offsetHeight);
cards.forEach((card, i) => { card.style.minHeight = heights[i] + 'px'; });
```

Make the risky part visible instead of hiding it behind a dense expression.

## What To Verify

- Measure the bottleneck before changing code.
- Reduce initial JavaScript and defer non-critical work.
- Remove references that outlive their screen, request, or component.
