## The Fastest JavaScript Is Code You Do Not Ship Yet

```javascript
async function openReports() {
  const { ReportsPanel } = await import('./ReportsPanel.js');
  return ReportsPanel.mount();
}
```

Code splitting keeps non-critical features out of the initial payload.

## Avoid Layout Thrashing

Bad pattern: read layout and write style repeatedly.

```javascript
for (const item of items) {
  const height = item.offsetHeight;
  item.style.width = `${height * 2}px`;
}
```

Better: read first, then write.

```javascript
const heights = items.map((item) => item.offsetHeight);

items.forEach((item, index) => {
  item.style.width = `${heights[index] * 2}px`;
});
```

## Common Leak Patterns

1. Global arrays that keep growing.
2. Event listeners not removed after unmount.
3. Timers and intervals that continue after the UI disappears.
4. Closures retaining large objects longer than needed.
