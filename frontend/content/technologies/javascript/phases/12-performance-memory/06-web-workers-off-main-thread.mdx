## Operational Context

Move CPU-heavy work away from rendering and input handling when splitting tasks is not enough. Slow JavaScript blocks interaction; leaked references make sessions degrade the longer users keep the app open. The useful answer is the one that predicts the next bug before it ships.

## Default Move

```javascript
const worker = new Worker(new URL('./worker.js', import.meta.url));
```

Prefer the version a teammate can modify safely during an incident or late-stage review.

## Risk Check

- Measure the bottleneck before changing code.
- Reduce initial JavaScript and defer non-critical work.
- Remove references that outlive their screen, request, or component.
