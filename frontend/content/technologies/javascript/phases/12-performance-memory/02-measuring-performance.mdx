## Operational Context

Use lab tools and real-user metrics before guessing at performance fixes. Slow JavaScript blocks interaction; leaked references make sessions degrade the longer users keep the app open. A good rule of thumb is only valuable if it helps you choose safer code under pressure.

## Default Move

```javascript
performance.mark('search-start');
await runSearch();
performance.measure('search', 'search-start');
```

Make the risky part visible instead of hiding it behind a dense expression.

## Risk Check

- Measure the bottleneck before changing code.
- Reduce initial JavaScript and defer non-critical work.
- Remove references that outlive their screen, request, or component.

Performance claims need evidence. Mention the metric, the tool, and the before/after behavior.
