## Where It Breaks

Find leaks from listeners, timers, detached DOM nodes, retained closures, and unbounded caches. Slow JavaScript blocks interaction; leaked references make sessions degrade the longer users keep the app open. The useful answer is the one that predicts the next bug before it ships.

## Ship This Shape

```javascript
debugger;
inspectRuntimeValue(state.currentUser);
```

Prefer the version a teammate can modify safely during an incident or late-stage review.

## Review Pass

- Measure the bottleneck before changing code.
- Reduce initial JavaScript and defer non-critical work.
- Remove references that outlive their screen, request, or component.
