## Bug Pattern

Use browser defenses that reduce the blast radius of injection bugs. Security issues in JavaScript often come from treating strings, origins, packages, or tokens as more trustworthy than they are. Treat the syntax as a tool, then explain the operational consequence.

## Production-Friendly Code

```javascript
Content-Security-Policy: script-src 'self'; object-src 'none'
```

Reach for cleverness only after the plain version has a measured problem.

## Interview Angle

- Trace source to sink before approving DOM changes.
- Avoid script-readable storage for sensitive credentials.
- Review dependency and CSP changes as part of the feature.

<Callout type="senior">
Security answers should be concrete: name the source, the sink, the attacker-controlled value, and the safer API.
</Callout>
