## Real Project Context

Understand browser security boundaries around credentials, cross-origin requests, and cookie-based auth. Security issues in JavaScript often come from treating strings, origins, packages, or tokens as more trustworthy than they are. A good rule of thumb is only valuable if it helps you choose safer code under pressure.

## Practical Implementation

```javascript
fetch('/api/session', { credentials: 'include' });
```

Make the risky part visible instead of hiding it behind a dense expression.

## Review Questions

- Trace source to sink before approving DOM changes.
- Avoid script-readable storage for sensitive credentials.
- Review dependency and CSP changes as part of the feature.
