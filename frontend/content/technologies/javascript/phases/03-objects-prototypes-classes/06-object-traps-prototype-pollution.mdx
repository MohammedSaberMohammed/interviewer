## When You Reach For It

Recognize dangerous dynamic property writes and defend object-merging code from prototype pollution. Object bugs usually look like missing fields, unexpected shared mutation, or inherited data being treated as trusted input. Keep the explanation tied to behavior you can observe in a debugger, test, or production incident.

## Concrete Pattern

```javascript
if (key === '__proto__' || key === 'constructor') {
  throw new Error('Unsafe key');
}
```

Keep the implementation explicit enough that ownership, failure, and the next likely change are easy to see.

## Trap To Avoid

- Check whether a property is own or inherited.
- Copy the nested branch you change, not just the top object.
- Reject dangerous dynamic keys before merging data.
