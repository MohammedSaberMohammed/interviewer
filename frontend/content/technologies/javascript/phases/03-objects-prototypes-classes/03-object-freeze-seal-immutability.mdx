## Bug Pattern

Use immutability where it helps and know the limits of shallow object protection. Object bugs usually look like missing fields, unexpected shared mutation, or inherited data being treated as trusted input. The useful answer is the one that predicts the next bug before it ships.

## Production-Friendly Code

```javascript
const frozen = Object.freeze({ nested: { enabled: true } });
frozen.nested.enabled = false; // nested object is still mutable
```

Prefer the version a teammate can modify safely during an incident or late-stage review.

## Interview Angle

- Check whether a property is own or inherited.
- Copy the nested branch you change, not just the top object.
- Reject dangerous dynamic keys before merging data.
