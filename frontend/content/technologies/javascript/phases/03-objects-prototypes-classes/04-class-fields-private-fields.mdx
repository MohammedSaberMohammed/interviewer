## Operational Context

Use modern class fields, private fields, static helpers, and constructors without confusing instance and prototype state. Object bugs usually look like missing fields, unexpected shared mutation, or inherited data being treated as trusted input. Use the concept to narrow the failure mode, not to recite trivia.

## Default Move

```javascript
class Session {
  #token;
  constructor(token) { this.#token = token; }
}
```

Leave the code in a shape that is easy to test at the behavior boundary.

## Risk Check

- Check whether a property is own or inherited.
- Copy the nested branch you change, not just the top object.
- Reject dangerous dynamic keys before merging data.
