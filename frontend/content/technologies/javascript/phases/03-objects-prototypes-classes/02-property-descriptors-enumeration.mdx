## Real Project Context

Understand own properties, inherited properties, enumerable keys, and why Object.keys and for...in differ. Object bugs usually look like missing fields, unexpected shared mutation, or inherited data being treated as trusted input. Anchor the concept in the runtime effect: what changes, what waits, what mutates, or what becomes unsafe.

## Practical Implementation

```javascript
Object.keys(user); // own enumerable keys
Object.hasOwn(user, 'role');
```

Write the code so the boundary is obvious: what comes in, what can fail, and what leaves the function.

## Review Questions

- Check whether a property is own or inherited.
- Copy the nested branch you change, not just the top object.
- Reject dangerous dynamic keys before merging data.
