## Where It Breaks

Build objects from small behaviors when inheritance would create fragile hierarchies. Object bugs usually look like missing fields, unexpected shared mutation, or inherited data being treated as trusted input. Use the concept to narrow the failure mode, not to recite trivia.

## Ship This Shape

```javascript
function createRepository(client) {
  return { findById: (id) => client.get('/items/' + id) };
}
```

Leave the code in a shape that is easy to test at the behavior boundary.

## Review Pass

- Check whether a property is own or inherited.
- Copy the nested branch you change, not just the top object.
- Reject dangerous dynamic keys before merging data.

<Callout type="senior">
Do not turn object questions into philosophy. Explain lookup, ownership, mutation, and the safer pattern you would ship.
