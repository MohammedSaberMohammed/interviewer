## Where It Breaks

Use observers and scheduling APIs for lazy loading, responsive UI, and smooth animation work. The browser is a shared runtime for rendering, input, accessibility, storage, and network events. Use the concept to narrow the failure mode, not to recite trivia.

## Ship This Shape

```javascript
const observer = new IntersectionObserver(([entry]) => {
  if (entry.isIntersecting) loadMore();
});
```

Leave the code in a shape that is easy to test at the behavior boundary.

## Review Pass

- Use safe DOM sinks for untrusted text.
- Prefer delegation for dynamic child elements.
- Release observers, timers, and listeners when ownership ends.
