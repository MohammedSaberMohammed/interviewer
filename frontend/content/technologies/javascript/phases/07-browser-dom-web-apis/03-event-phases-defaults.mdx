## Where It Breaks

Understand capturing, target, bubbling, preventDefault, and stopPropagation without breaking accessibility. The browser is a shared runtime for rendering, input, accessibility, storage, and network events. The useful answer is the one that predicts the next bug before it ships.

## Ship This Shape

```javascript
form.addEventListener('submit', (event) => {
  event.preventDefault();
  save(new FormData(form));
});
```

Prefer the version a teammate can modify safely during an incident or late-stage review.

## Review Pass

- Use safe DOM sinks for untrusted text.
- Prefer delegation for dynamic child elements.
- Release observers, timers, and listeners when ownership ends.
