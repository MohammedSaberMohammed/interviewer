## Failure Mode

Handle visibility changes, online/offline state, beforeunload limits, and cross-tab expectations. The browser is a shared runtime for rendering, input, accessibility, storage, and network events. Use the concept to narrow the failure mode, not to recite trivia.

## Working Pattern

```javascript
document.addEventListener('visibilitychange', () => {
  if (document.hidden) pausePolling();
});
```

Leave the code in a shape that is easy to test at the behavior boundary.

## What To Verify

- Use safe DOM sinks for untrusted text.
- Prefer delegation for dynamic child elements.
- Release observers, timers, and listeners when ownership ends.
