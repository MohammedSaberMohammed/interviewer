## Prefer Intentional DOM Updates

```javascript
const status = document.querySelector('[data-status]');
status.textContent = 'Saved';
```

Use `textContent` for text. Reach for `innerHTML` only when the HTML is trusted and sanitized.

## Event Delegation

Instead of adding a listener to every row, add one listener to a stable parent.

```javascript
const list = document.querySelector('[data-user-list]');

list.addEventListener('click', (event) => {
  const button = event.target.closest('[data-delete-user]');

  if (!button || !list.contains(button)) return;

  const userId = button.dataset.deleteUser;
  deleteUser(userId);
});
```

This works for rows added later because events bubble up to the parent.

## Clean Up Long-Lived Listeners

```javascript
function mount() {
  const onResize = () => updateLayout();
  window.addEventListener('resize', onResize);

  return () => {
    window.removeEventListener('resize', onResize);
  };
}
```

<Callout type="tip">
For modern event cleanup, you can also pass an AbortSignal to addEventListener and abort it when the feature unmounts.
</Callout>
