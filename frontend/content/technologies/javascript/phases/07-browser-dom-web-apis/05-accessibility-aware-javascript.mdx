## Real Project Context

Write interactions that work with keyboard, focus management, semantic HTML, and assistive technology. The browser is a shared runtime for rendering, input, accessibility, storage, and network events. The useful answer is the one that predicts the next bug before it ships.

## Practical Implementation

```javascript
button.addEventListener('click', submit);
button.addEventListener('keydown', handleKeyboardShortcut);
```

Prefer the version a teammate can modify safely during an incident or late-stage review.

## Review Questions

- Use safe DOM sinks for untrusted text.
- Prefer delegation for dynamic child elements.
- Release observers, timers, and listeners when ownership ends.
