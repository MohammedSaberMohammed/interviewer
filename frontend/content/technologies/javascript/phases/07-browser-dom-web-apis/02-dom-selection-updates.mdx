## Where It Breaks

Select, update, and create DOM nodes with safe APIs and predictable performance. The browser is a shared runtime for rendering, input, accessibility, storage, and network events. Use the concept to narrow the failure mode, not to recite trivia.

## Ship This Shape

```javascript
const formatter = new Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' });
formatter.format(19.99);
```

Leave the code in a shape that is easy to test at the behavior boundary.

## Review Pass

- Use safe DOM sinks for untrusted text.
- Prefer delegation for dynamic child elements.
- Release observers, timers, and listeners when ownership ends.
