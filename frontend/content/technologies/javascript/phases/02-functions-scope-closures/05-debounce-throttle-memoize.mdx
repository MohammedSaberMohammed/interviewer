## When You Reach For It

Learn the closure-based utilities used in search boxes, scroll handlers, resize handlers, and expensive calculations. Function behavior becomes visible when callbacks run later, methods are passed around, or a helper accidentally keeps old state alive. Anchor the concept in the runtime effect: what changes, what waits, what mutates, or what becomes unsafe.

## Concrete Pattern

```javascript
function debounce(fn, delay) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}
```

Write the code so the boundary is obvious: what comes in, what can fail, and what leaves the function.

## Trap To Avoid

- Name the variables the function closes over.
- Pick arrow or regular function based on this binding.
- Keep callback side effects obvious and test the logic around them.
