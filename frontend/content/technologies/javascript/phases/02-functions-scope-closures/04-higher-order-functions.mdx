## Failure Mode

Use functions that accept or return functions for filtering, retries, event handling, and small reusable policies. Function behavior becomes visible when callbacks run later, methods are passed around, or a helper accidentally keeps old state alive. Use the concept to narrow the failure mode, not to recite trivia.

## Working Pattern

```javascript
const byRole = (role) => (user) => user.role === role;
users.filter(byRole('admin'));
```

Leave the code in a shape that is easy to test at the behavior boundary.

## What To Verify

- Name the variables the function closes over.
- Pick arrow or regular function based on this binding.
- Keep callback side effects obvious and test the logic around them.
