## Operational Context

Separate deterministic transformation logic from I/O so code is easier to test, debug, and reuse. Function behavior becomes visible when callbacks run later, methods are passed around, or a helper accidentally keeps old state alive. The practical test is whether another engineer can predict the behavior from the code shape.

## Default Move

```javascript
function total(items) {
  return items.reduce((sum, item) => sum + item.price, 0);
}
```

Choose names and structure that preserve the business rule, not just the shortest syntax.

## Risk Check

- Name the variables the function closes over.
- Pick arrow or regular function based on this binding.
- Keep callback side effects obvious and test the logic around them.
