## Operational Context

Predict what can be read before declaration and explain why let and const fail differently from var. Function behavior becomes visible when callbacks run later, methods are passed around, or a helper accidentally keeps old state alive. The practical test is whether another engineer can predict the behavior from the code shape.

## Default Move

```javascript
console.log(count); // ReferenceError
let count = 1;
```

Choose names and structure that preserve the business rule, not just the shortest syntax.

## Risk Check

- Name the variables the function closes over.
- Pick arrow or regular function based on this binding.
- Keep callback side effects obvious and test the logic around them.
