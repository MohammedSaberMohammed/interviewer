## When You Reach For It

Review Node services for config validation, async errors, logging, health checks, timeouts, and dependency safety. Server-side JavaScript has to survive concurrency, slow dependencies, deploy signals, and malformed input. Use the concept to narrow the failure mode, not to recite trivia.

## Concrete Pattern

```javascript
await fetch(url, { signal: AbortSignal.timeout(3000) });
```

Leave the code in a shape that is easy to test at the behavior boundary.

## Trap To Avoid

- Fail fast on missing configuration.
- Add timeouts to outbound calls.
- Shut down gracefully instead of dropping in-flight work.
