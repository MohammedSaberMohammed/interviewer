## Where It Breaks

Understand Node scheduling enough to reason about timers, I/O, nextTick, and CPU blocking. Server-side JavaScript has to survive concurrency, slow dependencies, deploy signals, and malformed input. The practical test is whether another engineer can predict the behavior from the code shape.

## Ship This Shape

```javascript
Promise.resolve().then(() => console.log('microtask'));
setTimeout(() => console.log('timer'), 0);
```

Choose names and structure that preserve the business rule, not just the shortest syntax.

## Review Pass

- Fail fast on missing configuration.
- Add timeouts to outbound calls.
- Shut down gracefully instead of dropping in-flight work.
