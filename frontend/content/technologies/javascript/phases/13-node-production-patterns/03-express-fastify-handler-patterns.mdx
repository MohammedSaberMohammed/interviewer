## Where It Breaks

Structure request handlers around validation, service calls, status mapping, and centralized error handling. Server-side JavaScript has to survive concurrency, slow dependencies, deploy signals, and malformed input. A good rule of thumb is only valuable if it helps you choose safer code under pressure.

## Ship This Shape

```javascript
app.post('/orders', async (req, res, next) => {
  try { res.status(201).json(await createOrder(req.body)); }
  catch (error) { next(error); }
});
```

Make the risky part visible instead of hiding it behind a dense expression.

## Review Pass

- Fail fast on missing configuration.
- Add timeouts to outbound calls.
- Shut down gracefully instead of dropping in-flight work.
