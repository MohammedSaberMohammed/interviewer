## Bug Pattern

Handle SIGTERM, stop accepting work, finish in-flight requests, and close resources cleanly. Server-side JavaScript has to survive concurrency, slow dependencies, deploy signals, and malformed input. Treat the syntax as a tool, then explain the operational consequence.

## Production-Friendly Code

```javascript
process.on('SIGTERM', async () => {
  server.close();
  await db.close();
});
```

Reach for cleverness only after the plain version has a measured problem.

## Interview Angle

- Fail fast on missing configuration.
- Add timeouts to outbound calls.
- Shut down gracefully instead of dropping in-flight work.
