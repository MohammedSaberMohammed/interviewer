## Operational Context

Use streams for large files and understand why backpressure protects memory. Server-side JavaScript has to survive concurrency, slow dependencies, deploy signals, and malformed input. Anchor the concept in the runtime effect: what changes, what waits, what mutates, or what becomes unsafe.

## Default Move

```javascript
for await (const chunk of stream) {
  processChunk(chunk);
}
```

Write the code so the boundary is obvious: what comes in, what can fail, and what leaves the function.

## Risk Check

- Fail fast on missing configuration.
- Add timeouts to outbound calls.
- Shut down gracefully instead of dropping in-flight work.
