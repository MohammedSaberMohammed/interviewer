## Operational Context

Understand for...of, custom iterables, and generator functions where lazy sequences are useful. List transformations sit behind search, reports, tables, permissions, and API joins, so clarity and complexity both matter. Treat the syntax as a tool, then explain the operational consequence.

## Default Move

```javascript
function* ids(records) {
  for (const record of records) yield record.id;
}
```

Reach for cleverness only after the plain version has a measured problem.

## Risk Check

- Use map for shape changes, filter for removal, and reduce only when it stays readable.
- Build lookup maps before joining large collections.
- Copy arrays before mutating operations like sort.

<Callout type="senior">
The senior signal is choosing a structure that makes the next operation cheap and the current code readable.
</Callout>
