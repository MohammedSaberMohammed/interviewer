## Real Project Context

Choose the right collection for membership checks, entity lookup, metadata, and garbage-collection-friendly caches. List transformations sit behind search, reports, tables, permissions, and API joins, so clarity and complexity both matter. The useful answer is the one that predicts the next bug before it ships.

## Practical Implementation

```javascript
const usersById = new Map(users.map((user) => [user.id, user]));
const uniqueTags = [...new Set(tags)];
```

Prefer the version a teammate can modify safely during an incident or late-stage review.

## Review Questions

- Use map for shape changes, filter for removal, and reduce only when it stays readable.
- Build lookup maps before joining large collections.
- Copy arrays before mutating operations like sort.
