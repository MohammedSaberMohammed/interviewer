## Pick the Method That Says Your Intent

```javascript
const activeUsers = users.filter((user) => user.active);
const emails = activeUsers.map((user) => user.email);
const total = orders.reduce((sum, order) => sum + order.amount, 0);
```

If `reduce` becomes a puzzle, split the work or use a loop. Professional code is optimized for the next reader too.

## Use `Set` for Deduping

```javascript
const tags = ['react', 'js', 'react', 'node'];
const uniqueTags = [...new Set(tags)];
```

## Use `Map` for Fast Lookup

```javascript
const usersById = new Map(users.map((user) => [user.id, user]));
const owner = usersById.get(ticket.ownerId);
```

This is clearer and faster than repeatedly scanning an array with `find` inside another loop.

## Sorting Mutates

`sort` changes the array in place. Copy first when working with state.

```javascript
const sorted = [...users].sort((a, b) => a.name.localeCompare(b.name));
```
