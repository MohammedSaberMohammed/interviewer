## Why Teams Care

Transform API and UI data with array methods while keeping intent readable. List transformations sit behind search, reports, tables, permissions, and API joins, so clarity and complexity both matter. The useful answer is the one that predicts the next bug before it ships.

## Code Shape

```javascript
const activeEmails = users
  .filter((user) => user.active)
  .map((user) => user.email);
```

Prefer the version a teammate can modify safely during an incident or late-stage review.

## Readiness Check

- Use map for shape changes, filter for removal, and reduce only when it stays readable.
- Build lookup maps before joining large collections.
- Copy arrays before mutating operations like sort.
