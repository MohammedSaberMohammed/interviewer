## Operational Context

Compare storage options for auth-related data and understand XSS and CSRF tradeoffs. These flows combine user intent, server truth, transient failures, and data that may survive after the tab closes. Keep the explanation tied to behavior you can observe in a debugger, test, or production incident.

## Default Move

```javascript
// Store small preferences in localStorage.
// Prefer HttpOnly cookies for session tokens.
```

Keep the implementation explicit enough that ownership, failure, and the next likely change are easy to see.

## Risk Check

- Check response.ok instead of assuming fetch rejects on HTTP errors.
- Keep request state explicit in the UI.
- Store only values that are safe to expose to page scripts.
