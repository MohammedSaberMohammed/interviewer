## Why Teams Care

Collect form values, validate at the edge, and separate client convenience from server authority. These flows combine user intent, server truth, transient failures, and data that may survive after the tab closes. The practical test is whether another engineer can predict the behavior from the code shape.

## Code Shape

```javascript
const formData = new FormData(form);
const email = String(formData.get('email') ?? '').trim();
```

Choose names and structure that preserve the business rule, not just the shortest syntax.

## Readiness Check

- Check response.ok instead of assuming fetch rejects on HTTP errors.
- Keep request state explicit in the UI.
- Store only values that are safe to expose to page scripts.
