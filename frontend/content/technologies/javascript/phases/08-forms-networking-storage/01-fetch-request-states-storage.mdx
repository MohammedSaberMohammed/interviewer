## Fetch Does Not Reject on HTTP 500

```javascript
async function getJson(url, options) {
  const response = await fetch(url, options);

  if (!response.ok) {
    throw new Error(`Request failed: ${response.status}`);
  }

  return response.json();
}
```

`fetch` rejects for network-level failures. HTTP errors still produce a response object.

## Model UI States Explicitly

```javascript
const state = {
  status: 'idle', // idle | loading | success | empty | error
  data: null,
  error: null,
};
```

Clear states avoid screens that spin forever or show stale data after an error.

## Store Small, Non-Sensitive Values

```javascript
localStorage.setItem('theme', 'dark');
const theme = localStorage.getItem('theme') ?? 'system';
```

Do not store access tokens or sensitive personal data in localStorage. Treat browser storage as readable by script running on the page.

<Callout type="warning">
Before persisting form data, ask whether it is sensitive, whether it expires, and whether it must sync across tabs or devices. Storage choice is a product and security decision, not just a convenience.
</Callout>
