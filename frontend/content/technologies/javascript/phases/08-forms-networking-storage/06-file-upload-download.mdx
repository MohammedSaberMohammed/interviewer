## Operational Context

Handle File, Blob, multipart uploads, object URLs, and cleanup for download links. These flows combine user intent, server truth, transient failures, and data that may survive after the tab closes. The practical test is whether another engineer can predict the behavior from the code shape.

## Default Move

```javascript
const url = URL.createObjectURL(blob);
link.href = url;
URL.revokeObjectURL(url);
```

Choose names and structure that preserve the business rule, not just the shortest syntax.

## Risk Check

- Check response.ok instead of assuming fetch rejects on HTTP errors.
- Keep request state explicit in the UI.
- Store only values that are safe to expose to page scripts.
