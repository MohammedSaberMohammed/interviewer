## Where It Breaks

Understand the service worker and Cache API basics behind offline-first and resilient web apps. These flows combine user intent, server truth, transient failures, and data that may survive after the tab closes. Anchor the concept in the runtime effect: what changes, what waits, what mutates, or what becomes unsafe.

## Ship This Shape

```javascript
self.addEventListener('fetch', (event) => {
  event.respondWith(fetch(event.request));
});
```

Write the code so the boundary is obvious: what comes in, what can fail, and what leaves the function.

## Review Pass

- Check response.ok instead of assuming fetch rejects on HTTP errors.
- Keep request state explicit in the UI.
- Store only values that are safe to expose to page scripts.
