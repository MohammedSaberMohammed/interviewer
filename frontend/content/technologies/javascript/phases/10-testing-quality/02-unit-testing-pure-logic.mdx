## Real Project Context

Write fast, focused tests for deterministic transformations and business rules. Tests become valuable when they protect behavior and stay resilient while implementation changes. Anchor the concept in the runtime effect: what changes, what waits, what mutates, or what becomes unsafe.

## Practical Implementation

```javascript
function total(items) {
  return items.reduce((sum, item) => sum + item.price, 0);
}
```

Write the code so the boundary is obvious: what comes in, what can fail, and what leaves the function.

## Review Questions

- Use unit tests for deterministic rules.
- Mock network, time, storage, and third-party systems.
- Reserve e2e tests for flows the business cannot afford to break.
