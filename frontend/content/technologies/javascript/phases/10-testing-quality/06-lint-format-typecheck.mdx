## Where It Breaks

Use automated checks to keep code review about behavior instead of style debates. Tests become valuable when they protect behavior and stay resilient while implementation changes. Treat the syntax as a tool, then explain the operational consequence.

## Ship This Shape

```javascript
pnpm lint
pnpm typecheck
pnpm test
```

Reach for cleverness only after the plain version has a measured problem.

## Review Pass

- Use unit tests for deterministic rules.
- Mock network, time, storage, and third-party systems.
- Reserve e2e tests for flows the business cannot afford to break.
