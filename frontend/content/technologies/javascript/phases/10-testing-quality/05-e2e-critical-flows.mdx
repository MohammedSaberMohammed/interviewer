## When You Reach For It

Use end-to-end tests sparingly for the flows that must never break. Tests become valuable when they protect behavior and stay resilient while implementation changes. A good rule of thumb is only valuable if it helps you choose safer code under pressure.

## Concrete Pattern

```javascript
await page.getByRole('button', { name: 'Checkout' }).click();
```

Make the risky part visible instead of hiding it behind a dense expression.

## Trap To Avoid

- Use unit tests for deterministic rules.
- Mock network, time, storage, and third-party systems.
- Reserve e2e tests for flows the business cannot afford to break.
