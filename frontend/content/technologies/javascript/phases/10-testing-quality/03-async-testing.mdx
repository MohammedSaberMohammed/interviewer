## Operational Context

Test promises, timers, retries, and loading states without race conditions or arbitrary sleeps. Tests become valuable when they protect behavior and stay resilient while implementation changes. Anchor the concept in the runtime effect: what changes, what waits, what mutates, or what becomes unsafe.

## Default Move

```javascript
const result = input == null ? fallback : transform(input);
```

Write the code so the boundary is obvious: what comes in, what can fail, and what leaves the function.

## Risk Check

- Use unit tests for deterministic rules.
- Mock network, time, storage, and third-party systems.
- Reserve e2e tests for flows the business cannot afford to break.
