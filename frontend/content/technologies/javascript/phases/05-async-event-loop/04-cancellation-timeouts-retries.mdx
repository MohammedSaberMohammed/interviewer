## Failure Mode

Build resilient request flows that cancel stale work, time out slow calls, and retry only safe operations. The bug often appears only under latency: stale responses, swallowed rejections, blocked rendering, or tasks finishing out of order. A good rule of thumb is only valuable if it helps you choose safer code under pressure.

## Working Pattern

```javascript
const controller = new AbortController();
setTimeout(() => controller.abort(), 5000);
await fetch(url, { signal: controller.signal });
```

Make the risky part visible instead of hiding it behind a dense expression.

## What To Verify

- Start independent work together.
- Use allSettled when partial failure is still useful.
- Add cancellation or timeout behavior at user and network boundaries.
