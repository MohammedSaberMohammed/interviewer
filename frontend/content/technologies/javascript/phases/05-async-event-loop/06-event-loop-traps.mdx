## Real Project Context

Avoid starvation, timer assumptions, and ordering mistakes across browser and Node runtimes. The bug often appears only under latency: stale responses, swallowed rejections, blocked rendering, or tasks finishing out of order. The useful answer is the one that predicts the next bug before it ships.

## Practical Implementation

```javascript
Promise.resolve().then(() => console.log('microtask'));
setTimeout(() => console.log('timer'), 0);
```

Prefer the version a teammate can modify safely during an incident or late-stage review.
