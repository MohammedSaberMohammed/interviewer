## Why Teams Care

Use all, allSettled, race, and any for real concurrency requirements. The bug often appears only under latency: stale responses, swallowed rejections, blocked rendering, or tasks finishing out of order. Anchor the concept in the runtime effect: what changes, what waits, what mutates, or what becomes unsafe.

## Code Shape

```javascript
const [user, permissions] = await Promise.all([
  fetchUser(id),
  fetchPermissions(id),
]);

const results = await Promise.allSettled(batch.map(saveItem));
```

Write the code so the boundary is obvious: what comes in, what can fail, and what leaves the function.
