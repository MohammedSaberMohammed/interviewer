## Where It Breaks

Understand callback-style APIs, promisification, and how promise chains improve error flow. The bug often appears only under latency: stale responses, swallowed rejections, blocked rendering, or tasks finishing out of order. Use the concept to narrow the failure mode, not to recite trivia.

## Ship This Shape

```javascript
readFile('config.json')
  .then(JSON.parse)
  .catch(reportConfigError);
```

Leave the code in a shape that is easy to test at the behavior boundary.

## Review Pass

- Start independent work together.
- Use allSettled when partial failure is still useful.
- Add cancellation or timeout behavior at user and network boundaries.
