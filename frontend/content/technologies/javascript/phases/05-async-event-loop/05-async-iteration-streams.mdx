## Real Project Context

Process values arriving over time without buffering everything in memory. The bug often appears only under latency: stale responses, swallowed rejections, blocked rendering, or tasks finishing out of order. The useful answer is the one that predicts the next bug before it ships.

## Practical Implementation

```javascript
for await (const chunk of stream) {
  processChunk(chunk);
}
```

Prefer the version a teammate can modify safely during an incident or late-stage review.
