## Bug Pattern

Avoid common coercion bugs in form values, query strings, flags, and conditional rendering. A small assumption here can corrupt state, hide valid user input, or make an API response look safer than it is. Use the concept to narrow the failure mode, not to recite trivia.

## Production-Friendly Code

```javascript
const hasItems = Array.isArray(items) && items.length > 0;
const pageSize = input.pageSize ?? 25;
```

Leave the code in a shape that is easy to test at the behavior boundary.

## Interview Angle

- Confirm the actual runtime type before leaning on syntax.
- Default missing values without replacing valid falsy values.
- Normalize external data once, close to the boundary.
