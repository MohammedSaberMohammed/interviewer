## Failure Mode

Know when JavaScript copies a value and when it copies a reference, especially in state updates and API mapping. A small assumption here can corrupt state, hide valid user input, or make an API response look safer than it is. Use the concept to narrow the failure mode, not to recite trivia.

## Working Pattern

```javascript
const original = { profile: { name: 'Ava' } };
const shallow = { ...original };
shallow.profile.name = 'Nora';
console.log(original.profile.name); // 'Nora'
```

Leave the code in a shape that is easy to test at the behavior boundary.

## What To Verify

- Confirm the actual runtime type before leaning on syntax.
- Default missing values without replacing valid falsy values.
- Normalize external data once, close to the boundary.
