## Operational Context

Understand what JSON preserves, what it drops, and why API data should be validated before the app trusts it. A small assumption here can corrupt state, hide valid user input, or make an API response look safer than it is. Use the concept to narrow the failure mode, not to recite trivia.

## Default Move

```javascript
const payload = JSON.parse(raw);
const createdAt = new Date(payload.createdAt);
```

Leave the code in a shape that is easy to test at the behavior boundary.

## Risk Check

- Confirm the actual runtime type before leaning on syntax.
- Default missing values without replacing valid falsy values.
- Normalize external data once, close to the boundary.
