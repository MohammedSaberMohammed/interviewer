## Real Project Context

Use destructuring, rest/spread, template literals, optional chaining, and nullish coalescing without creating hidden bugs. A small assumption here can corrupt state, hide valid user input, or make an API response look safer than it is. Use the concept to narrow the failure mode, not to recite trivia.

## Practical Implementation

```javascript
const displayName = user.profile?.displayName ?? 'Anonymous';
const tags = [...defaultTags, ...customTags];
```

Leave the code in a shape that is easy to test at the behavior boundary.

## Review Questions

- Confirm the actual runtime type before leaning on syntax.
- Default missing values without replacing valid falsy values.
- Normalize external data once, close to the boundary.
